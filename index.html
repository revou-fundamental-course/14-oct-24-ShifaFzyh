Website Profile

Profile

 Website Wolfchany ini adalah website yang dibuat untuk mengenalkan tentang Skzoo, yaitu simbol karakter animasi dari para anggota Stray Kids. Dan Stray Kids adalah boy group asal Korea Selatan yang berjumlah 8 anggota.

Vision

Untuk mengenalkan nama dan karakter Skzoo dari masing-masing member Stray Kids.

Mission
  • Sebagai hiburan untuk para pembaca yang menyukai Skzoo dan Stray Kids.
  • Menjadikan web ini sebagai awal untuk mengetahui Stray Kids.
  • Untuk menyelesaikan tugas mini coding project dari RevoU Fundamental Course.

Member Skzoo
